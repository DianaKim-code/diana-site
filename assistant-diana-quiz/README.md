# Ассистент Дианы

Отдельная интерактивная квиз-страница-заявка. Пользователь проходит ассистента по шагам: приветствие, выбор направления, вопросы только по выбранной ветке, промежуточный вывод, контакт, отправка заявки и финальное сообщение.

## Файлы

- `index.html` — разметка страницы.
- `style.css` — визуальный стиль, адаптивность, кнопки, карточки, прогресс.
- `script.js` — логика квиза, ветки, условные поля, сборка заявки и отправка.

## Как открыть локально

Можно открыть `index.html` в браузере напрямую. Для проверки как на GitHub Pages удобнее запустить любой локальный статический сервер и открыть папку `assistant-diana-quiz/`.

## Где редактировать тексты и ответы

Все вопросы, варианты ответов, промежуточные выводы и заголовки заявок находятся в `script.js` в объекте:

```js
const quizData = {
  money: {},
  digital: {},
  deck: {},
  support: {}
};
```

В каждом вопросе есть:

- `id` — внутреннее имя ответа.
- `label` — подпись для текста заявки.
- `type` — `choice`, `text` или `message`.
- `text` — вопрос или текст кнопки.
- `options` — варианты ответа для `choice`.
- `placeholder` и `hint` — подсказки для текстовых полей.
- `condition` — условие показа поля.

## Как подключить отправку

В `script.js` есть строка:

```js
const SUBMISSION_ENDPOINT = "";
```

Вставьте туда endpoint выбранного сервиса.

### Formspree

1. Создайте форму в Formspree.
2. Скопируйте endpoint вида `https://formspree.io/f/xxxxxxx`.
3. Вставьте его в `SUBMISSION_ENDPOINT`.
4. Проверьте отправку на опубликованной странице.

### Google Apps Script / Make / Zapier

1. Создайте webhook, который принимает `POST`.
2. Настройте сохранение в Google Sheets, отправку на email или Telegram.
3. Вставьте webhook URL в `SUBMISSION_ENDPOINT`.
4. Не размещайте приватные токены Telegram-бота в публичном JavaScript.

### EmailJS

Можно подключить отдельно через SDK EmailJS, но публичные ключи и шаблоны нужно настроить аккуратно. Не храните секретные ключи в открытом коде.

## Если отправка не подключена или не сработала

Квиз покажет сообщение, что заявку не удалось отправить автоматически, и предложит кнопку `Скопировать заявку`. Это защищает ответы пользователя от потери.

## Как изменить стиль

Основные цвета находятся в начале `style.css`:

```css
:root {
  --bg: #f7f1e9;
  --surface: #fffaf3;
  --accent: #7a2f3f;
  --green: #496b5a;
}
```

Можно менять фон, акцент, цвет текста и границы, сохраняя мягкий премиальный характер страницы.

## Размещение на GitHub Pages

1. Загрузите папку `assistant-diana-quiz/` в репозиторий.
2. В настройках GitHub Pages выберите ветку и папку публикации.
3. Страница будет доступна по пути вида `/assistant-diana-quiz/`.
4. После публикации проверьте прохождение всех веток и отправку заявки.
